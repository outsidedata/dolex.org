Query Engine

One question in, finished chart out

Other AI tools write code, run it, read the output, and repeat until they get it right. Dolex skips all that — it has a built-in query engine that goes straight from your question to a finished chart.

Without Dolex

1.AI writes code to load the CSV
2.Runs it in a sandbox, reads the output
3.Writes more code to crunch the numbers
4.Runs it again, reads the result
5.Writes code to draw a basic chart
6.Repeat if the chart needs changes
3–6 round trips · full dataset in context · slow

With Dolex

1.Claude sees a summary of your data — column names, types, stats
2.Claude asks Dolex to answer a question about the data
3.Dolex crunches the numbers locally and picks the right chart
4.You get a finished visualization — instantly
1 round trip · zero rows in context · instant
