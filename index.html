A query engine, not a REPL loop

AI assistants today write Python, execute it in a sandbox, read the output, and repeat. Dolex gives the AI a declarative query language instead — one query in, finished chart out.

Without Dolex

1.AI writes pandas code to load the CSV
2.Sandbox executes it, returns output
3.AI writes more code to group & aggregate
4.Sandbox executes, AI reads the numbers
5.AI writes matplotlib code for a bar chart
6.Repeat if the chart needs changes
3–6 round trips · full dataset in context · slow

With Dolex

1.AI sees column profiles: types, stats, top values
2.AI writes one declarative query (joins, aggregations, filters)
3.Dolex executes it locally, picks the right chart
4.Returns the finished visualization
1 round trip · zero rows in context · instant
